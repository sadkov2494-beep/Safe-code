# Release builds

- `safe-code-release.apk` is a release APK build of Safe Code for direct Android installation.
- `safe-code-release.aab` is a release Android App Bundle build intended for Google Play internal testing or production after release signing is configured.

If Android blocks installation, enable installation from unknown sources for the browser or file manager used to open the APK.

Production store uploads still require owner-controlled signing keys and real AdMob ids.
