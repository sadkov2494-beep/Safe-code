# Safe Code privacy policy draft

Last updated: 2026-05-18

Safe Code is a logic puzzle game. This draft is provided as a starting point and
must be reviewed and published by the app owner before store release.

## Data stored on device

The game stores progress locally on the device:

- completed levels;
- best stars;
- daily safe streak;
- notebook notes and digit marks;
- theme and onboarding state.

This local data is not sent to our servers by the current app build.

## Advertising

The app integrates Google Mobile Ads. Development builds use Google test ads. If
production ads are enabled, Google may process data such as device identifiers,
ad interactions, diagnostics, approximate location inferred by Google services
and other advertising-related information according to Google's policies.

Google privacy information:

https://policies.google.com/privacy

## Analytics

The current build does not include Firebase Analytics or Crashlytics. If analytics
or crash reporting are added later, this policy and store disclosures must be updated.

## Children

Safe Code is not designed for children under 13. If you choose to publish it for a
children/family audience, configure ads and store declarations according to the
applicable child-directed policies.
