# Код Сейфа / Safe Code

MVP мобильной 2D-логической игры на Flutter без Unity. Игрок открывает сейфы, анализируя Mastermind-подсказки, логические ограничения и визуальные улики. Проект работает из одного кода на Android и iOS, использует портретную ориентацию, темную тему по умолчанию и локальное сохранение прогресса.

## Что внутри

- 30 заранее созданных логических уровней:
  - 10 простых уровней с кодами из 3 цифр;
  - 10 средних уровней с кодами из 4 цифр;
  - 10 сложных уровней с кодами из 4-5 цифр.
- Экраны: главное меню, выбор уровня, игровой экран сейфа, победа, обучение, настройки.
- Пять фоновых сцен за сейфом: архив, серверная, склад, лифт и контейнер.
- Главы с короткими вступительными текстами перед группами дел.
- Внутриигровой блокнот для отметок цифр и заметок по каждому сейфу.
- Коллекция открытых сейфов с кодами, звездами и датой открытия.
- Ежедневный уникальный сейф, детерминированный по текущей дате.
- First-run onboarding на 1-2 минуты перед первым сейфом.
- Yandex Ads-интеграция с rewarded ads и interstitial-рекламой между уровнями на тестовых Yandex demo ID.
- Daily streak, лучший daily streak и достижения в коллекции.
- Игровые WAV-звуки: щелчки клавиш, удаление, ошибка, подсказка и открытие сейфа.
- Зацикленная фоновая мелодия для меню и игровых экранов; настройки отдельно отключают эффекты и музыку.
- Бесплатные MVP-инструменты: сканер отпечатков, тепловизор, дешифратор, анализатор и прослушка.
- Прогрессия: последовательное открытие уровней, переигрывание, лучший результат по звездам, общий прогресс и отдельный daily safe.

## Как запустить

```bash
cd Safe-code
flutter pub get
flutter run
```

## Как запустить тесты

```bash
cd Safe-code
flutter test
```

Дополнительно рекомендуется запускать анализатор:

```bash
flutter analyze
```

## Как собрать Android

Если в Cloud Agent окружении еще нет Flutter или Android SDK, сначала выполните из корня репозитория:

```bash
bash scripts/setup-flutter-android.sh
```

```bash
cd Safe-code
flutter build apk
```

Для релизной публикации можно использовать:

```bash
flutter build appbundle
```

Перед публикацией замените тестовые Yandex Ads ID, настройте release signing и проверьте:

- `docs/YANDEX_ADS_SETUP.md`
- `docs/RUSTORE_RELEASE_CHECKLIST.md`
- `docs/STORE_RELEASE_CHECKLIST.md`
- `docs/PRIVACY_POLICY_DRAFT.md`

## Как собрать iOS

Сборка iOS требует macOS и Xcode:

```bash
cd Safe-code
flutter build ios
```

## Как добавлять новые уровни

1. Откройте `lib/data/levels.dart`.
2. Добавьте новый `Level` с уникальным `id`.
3. Заполните:
   - `title`;
   - `difficulty`;
   - `codeLength`;
   - `correctCode`;
   - `maxAttempts`;
   - `logicalClues`;
   - `visualClues`;
   - `availableTools`;
   - `softHint`;
   - `solutionExplanation`.
4. Убедитесь, что код решается логически, а не перебором.
5. Запустите `flutter test`, чтобы проверить уникальность id, длину кодов и наличие объяснений.

## Где настроена реклама

Рекламная интеграция находится в `lib/services/ad_service.dart`.

Сейчас используются официальные тестовые Yandex demo ID. Перед публикацией передайте реальные ad unit ids через `--dart-define`, как описано в `docs/YANDEX_ADS_SETUP.md`.

- `RewardedAdPlacement.extraHint` — дополнительная подсказка;
- `RewardedAdPlacement.extraAttempt` — дополнительная попытка;
- `RewardedAdPlacement.skipLevel` — пропуск уровня.
- `InterstitialAdPlacement.betweenLevels` — реклама между уровнями.

Игровая интеграция находится в `lib/screens/game_screen.dart` в меню паузы.
